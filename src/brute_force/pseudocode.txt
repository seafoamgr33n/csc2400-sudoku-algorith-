import random and json

class board
    vars including:
    list, the list that holds all the cell objects
    empty cells, the list that holds all the empty cells

class cell
    vars including:
    row, col, box(3x3), num, id, and tried solutions

def init board
    loop that creates all cells and sets row, col, box and id
    if generating random puzzle:
        value = 0
    if loading in a puzzle from json file:
        value = json file value at [r][c]

def set empty cells
    if cell is empty originally, add to list empty cells

def print board
    print the board

def is valid
    before the number is placed in a cell, it checks
    if that number exists in the row, col, and box

    if the number is 0 it is not valid

    returns true or false

def backtracking
    at the index where there is a 0 because no number is valid,
    go back one cell and add its value to tried sols.

    then if the cell was originally an empty cell, (aka not a set value
    imported from json) check to see if a value 1-9 has already been tried and
    if it hasn't AND it is a valid value, add it to that spot

    else
    add to tried sols. if tried sols is full, clear the list, set the value
    to 0, and backtrack again

    returns the new index (value to the left of the 0 index)

def brute force
    validating that the imported board is valid

    if generating random puzzle:
        get random array with numbers 1-9, set row 0 to that
        set i to 9 (first spot row 1)

    else loading json file:
        set i to 0

    while i < 81
    if the cell is empty iterate numbers until one is valid
    if it has tried all numbers and is still not valid, call backtracking

    if all cells are full, print complete board and print board

main
    create board object
    init board
    set empty cells
    brute force
